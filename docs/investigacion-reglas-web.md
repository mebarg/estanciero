Consulta: 3 de noviembre de 2026. Objetivo: contrastar las diferencias encontradas entre el EXE 0.45, su imagen de tablero, las tarjetas conservadas y el reglamento aportado.

La búsqueda permite respaldar varias reglas, pero no resuelve todos los importes. No se modificó el motor a partir de resúmenes sin procedencia verificable. La ausencia de un documento en esta búsqueda no prueba que no exista.

## Qué respaldan los reglamentos

El manual 60 Aniversario y su otra copia coinciden en: Descanso opcional de dos turnos, con anuncio previo; interés hipotecario del 10% adelantado; venta de mejoras al banco por la mitad; construcción pareja; y cobros de alquileres y premios que vencen con la próxima tirada. Estas reglas ya están implementadas.

En Comisaría, esa edición incluye caer directamente en la casilla entre los motivos de prisión. El resumen de una página lo considera una visita. El manual tampoco establece liberación automática después de dos o tres intentos fallidos. Por eso se conserva la regla elegida y no se toma una variante de Internet como corrección universal.

El manual remite al tablero para comprar títulos y a las escrituras para alquileres, mejoras y valores hipotecarios. Esto respalda usar los documentos físicos como criterio, pero no certifica los importes particulares de nuestros archivos.

## Criterio que se mantiene

Se conserva el manual aportado para las reglas, el tablero visible para recorrido y precios impresos, las escrituras locales para alquileres y mejoras, los reversos para hipotecas y el EXE para los datos recuperados sin equivalente visible, como el precio de las compañías. Se preservan las discrepancias para permitir una futura variante que reproduzca los valores del programa viejo.

El 10% adelantado está expresamente respaldado por el manual. Devolver sólo el principal al cancelar una hipoteca constituida por el mismo propietario sigue siendo la interpretación documentada de la app; la búsqueda no encontró una aclaración del fabricante con un ejemplo numérico que cierre ese caso.

No se pudo determinar si cada diferencia del EXE responde a una adaptación deliberada, un error o una mezcla de ediciones. Tampoco corresponde concluir que falta información necesaria para jugar: la versión actual tiene valores definidos y su procedencia documentada.
